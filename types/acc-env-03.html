Knowledge card

Naming and describing the accounting concepts

Written

Each accounting concept is a rule with one key idea: right period, separate from the owner, same each year, too small to matter, measured in money, or not overstated. Find the key idea and you can name the concept.

1

Which concept is this?

Decide first, then tap the ? to check.

5 concepts to find

Find the key idea in each rule and name the concept it describes.

  1. Right period
  2. Separate from owner
  3. Same each year
  4. Too small to matter
  5. Cautious figure

Right period

Key idea
Income and expenses belong to the year they relate to.
Write it as
Accruals: record income and expenses in the period they belong to.

Separate from owner

Key idea
The owner and the business are two different things.
Write it as
Business entity: the owner's private items stay out of the books.

Same each year

Key idea
Methods do not change, so years can be compared.
Write it as
Consistency: the same method is used every year.

Too small to matter

Key idea
Low-value items can simply be treated as expenses.
Write it as
Materiality: very small items need not be recorded separately.

Cautious figure

Key idea
Never show profit or assets too high.
Write it as
Prudence: profits and assets are not overstated.

Exam tipPrudence is about caution; consistency is about sameness. Do not swap them.

3 concepts to find

Find the items that are not accounting concepts.

  1. Going concern
  2. Ethics, not a concept
  3. Quality, not a concept

Going concern

Meaning
The business will keep trading for the foreseeable future.
Not the same as
Business entity, which keeps the owner separate.

Ethics, not a concept

Why
Confidentiality is about how an accountant behaves.
Do this
Cross out ethics words first in a choice question.

Quality, not a concept

Why
Comparability describes useful information, not a concept here.
Remember
The concepts are the six rules plus going concern.

Exam tipWords such as integrity, objectivity, duality and understandability are distractors.

4

The method

  1. Learn one line each

    Know a one-line meaning for each concept.

  2. Find the key idea

    Look for: right period, separate owner, same each year, small, money value, caution.

  3. Name it and describe it

    Write the full name, e.g. money measurement; describe without repeating it.

  4. Remove distractors

    Cross out ethics principles and qualities of information first.

Do not lose marks here

  • ✗
    Prudence or consistency

    Prudence is caution; consistency is using the same method each year.

  • ✗
    Repeating the name

    "Consistency means being consistent" earns no description mark.

  • ✗
    Entity or going concern

    Entity separates the owner; going concern means the business carries on.

  • ✗
    Same concept twice

    When three are asked, give three different concepts.

What a complete response includes

Each correct concept name earns one mark. In longer items each matching description earns a further mark. Names of ethics principles or qualities of information score nothing.

After your attempt, see the full worked explanation

Worked explanation

  1. Row 1 says low-value items need not be recorded separately. The key idea is 'too small to matter', which is materiality.
  2. Row 2 says only items measured in money should be recorded. The key idea is 'a money value', which is money measurement.
  3. Row 3 says the business is separate from its owner. The key idea is 'separate from the owner', which is business entity.
  4. Write each concept name in the right-hand column.
Model answer · written by olevels.com, not an official Pearson mark scheme

Low-value items do not need separate recording -> Materiality Only items that can be measured in money should be recorded -> Money measurement The business is treated as completely separate from the owner -> Business entity

How the marks are earned

One mark for each correct concept name, 3 marks in total. The exact name is required; a description instead of a name does not score.
