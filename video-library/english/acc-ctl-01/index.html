Why keep a trial balance? Benefits and limits

Idea. Imagine adding up a long shopping receipt twice and getting the same total. You know the adding is right. But if the shop charged you for the wrong item, the total would still add up. A trial balance works the same way. A trial balance is a list of every ledger balance on one date, with debits in one column and credits in the other. It is a list, not an account, so it is not part of the double entry. So what does it do? It tests the arithmetic of the double entry, gathers the balances for the financial statements, and warns you when totals differ. But some errors leave the totals equal, such as omission, commission and principle.

Method. First, read the command word and the marks. State wants short points. Explain wants a point and a reason. Evaluate wants both sides and a judgement. For a benefit, make the point, then develop it. A trial balance checks the arithmetic of the double entry, because every debit has an equal credit, so the two totals must agree. For a limitation, say that agreeing totals do not prove the books are correct, and name an error that stays hidden. Then finish with a clear judgement, using the trader's name.

Worked example. Here is a real question from June 2021. Jacques prepares a trial balance. We must evaluate the advantages and disadvantages of preparing one. Five marks. Earlier in the question, Jacques found errors. Error one: motor insurance was posted to the motor vehicles account. An expense went into an asset account. That is an error of principle. The advantage. A trial balance checks the arithmetic of Jacques's double entry, because the total of the debit balances should equal the total of the credit balances. The disadvantage. Totals that agree do not prove the books are correct. The motor insurance was still debited and credited with the same amount, so the totals agree, but the error is hidden. Finally, the judgement. On balance, Jacques should keep preparing a trial balance. It is a quick, useful check before he prepares his financial statements, even though it will not catch every error. Common mistake. A common mistake is saying that a balanced trial balance proves there are no errors. It only shows that the debits equal the credits. Another is writing only advantages, with no conclusion. Evaluate needs both sides, then a judgement.
