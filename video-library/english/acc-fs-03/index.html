Will profit (or working capital) go up, down or stay the same?

Idea. You pay back ten dollars you borrowed from a friend. Your cash goes down, but are you poorer? No. You also owe ten dollars less. Profit works the same way: it only changes when income or an expense changes. More income or less expense raises profit. More expense or less income lowers it. Capital, drawings, buying a non-current asset, or paying a debt only move assets, liabilities and capital, so profit stays the same.

Method. Write the double entry first. If neither account is income or an expense, there is no effect. If income rises or an expense falls, profit increases. The opposite, and profit decreases. For an error, compare profit now with what it should be. An expense left out, such as rent owing, makes profit too high: overstated. A prepayment ignored makes the expense too high, so profit is understated. Working capital is current assets minus current liabilities. It only changes if the total of either changes. Moving cash into the bank swaps two current assets, so there is no effect.

Worked example. Here is a real question from November 2024. Which transaction would affect a business's profit? One mark. Write the double entry for each option. Option A: selling an asset at its book value. Debit bank, credit the asset, with the same amount. There is no gain and no loss, so no effect on profit. Option B: paying a supplier and receiving a discount. Debit the supplier with the full debt. Credit bank with the amount paid, and discount received with the rest. Discount received is income, so profit increases. Option C: paying a debt in full. Debit the supplier, credit bank. A liability and an asset both fall. Option D: cash paid into the bank. Debit bank, credit cash. Two assets swap. Neither changes profit. So the answer is B. It is the only option that touches an income account. Common mistake. A common mistake is thinking any cash going out lowers profit. Drawings reduce the owner's capital, not profit. Another is getting omissions backwards. If an expense was left out, profit is too high, so it is overstated.
