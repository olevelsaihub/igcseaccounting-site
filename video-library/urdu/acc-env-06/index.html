Idea۔ آپ کے فون پر passcode ہے، اور آپ کی photos شاید cloud پر backup ہوں۔ Business بھی اپنے computer پر accounting records کو اسی طرح کے طریقوں سے محفوظ رکھتا ہے۔ Data دو بڑے طریقوں سے خطرے میں ہوتا ہے۔ وہ ضائع یا خراب ہو سکتا ہے۔ یا ایسے لوگ اسے دیکھ یا بدل سکتے ہیں جنہیں رسائی نہیں ہونی چاہیے۔ اسے unauthorised access کہتے ہیں۔

Method۔ Step ایک۔ طے کریں کہ question کس بارے میں ہے: access روکنا، loss روکنا، یا دونوں۔ Step دو۔ Access روکنے کے لیے passwords، firewall، anti-virus software، encryption، یا locked rooms استعمال کریں۔ Loss روکنے کے لیے regular backups لیں اور copies off-site یا cloud میں رکھیں۔ Step تین۔ ہر mark کے لیے ایک مختلف measure چند الفاظ میں لکھیں۔ State question میں لمبی وضاحت کی ضرورت نہیں۔

Common Mistake۔ عام غلطی ایک ہی method کو مختلف الفاظ میں دو بار لکھنا ہے۔ Passwords اور secret login codes ایک ہی idea ہیں، اس لیے ایک mark ملتا ہے۔ ایک اور غلطی مبہم بات لکھنا ہے، جیسے keep it safe، یا computers کا کوئی benefit دینا۔ مخصوص measure کا نام لکھیں۔
